# Elections Position Content Block

<Description of={ElectionsPositionContentBlockStories.Filing} />

## Overview

The body of a position page below the hero. A side rail on the left, shown on desktop only ("On this
page" links and an "Explore more races" card whose "GoodParty.org Pledge" opens the pledge pop-up),
and a column on the right holding: the candidates list and the officeholders list (each with an intro
sentence, the pledge explainer and, where the route built one, the seat filter in the heading row),
the voter readiness card, the About card and the How to run steps.

The block has one `state`, shared with the hero (`resolvePositionHeroState`), so the two can never
disagree about where the race is in its cycle. Before the filing window opens the About card and the
How to run steps lead and the people lists follow (`leadsWithAbout`); from the day filing opens the
people lead. Filing and mid-election otherwise render the same body. Once decided, the list heading
becomes the results heading, winners get an ELECTED tag and the "This election is over" banner
appears above the steps.

## Hiding rules

Every data-fed section hides on its own when a page has nothing for it, and the "On this page"
links name only the sections that rendered, in the order they render:

- Candidates and officeholders: hidden when `undefined` (no data) and when empty.
- Pledge explainer: drawn inside each people list, so it goes with the list.
- Seat filter: hidden unless the route built one with more than one option.
- About: hidden without a description or an attribute.
- How to run steps 1 and 2: hidden without eligibility or filing data. Step 3 is editorial and always shows.
- Explore card: hidden without a location href. The whole rail is hidden below desktop width.
- Voter readiness illustrations: only drawn when an editor has uploaded them; the defaults are text and links.

## Where the data comes from

On the position pages the section wrapper (`ElectionsPositionContentBlockSection`) receives the
route's override from `buildPositionContentOverride`: the race dates, the same candidate rows the
hero shows, the current officeholders (`loadPositionOfficeholders`), the race facts for the About
card and the filing details for the steps. Every sentence is a Sanity field with a default in
`POSITION_CONTENT_DEFAULTS`, resolved with the page's tokens (`[office name]`, `[Position Name]`,
`[County or City]`).
